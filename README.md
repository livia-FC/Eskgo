# eskgo.

Protótipo navegável de app financeiro (HTML + JS, Supabase, Vercel).

- `index.html`: o app (boas-vindas, login/cadastro, Home, Cartões, Metas, Conta)
- `supabase/migrations`: esquema, RLS e políticas de admin
- `prisma/schema.prisma`: documentação do esquema
- `girl.webp`: foto da tela de boas-vindas (fica no bucket público `brand` do Supabase Storage)
- `CHECKLIST.md`: estado do projeto e pendências

Deploy: Vercel (`vercel.json`). Produção: https://eskgo-livia-fc.vercel.app
